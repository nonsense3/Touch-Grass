## 🌿 What Is This?

**Touch Grass** is a brutalist, edge-native, 100% offline open-source AI system designed around a radical premise: **the screen should be the shortest part of the experience (sub-15 seconds).**

Every commercial AI product is engineered for *continuous engagement* — keeping you staring at glass. Touch Grass is engineered for the exact opposite: **prompt eviction**. Get your answer in 40ms, lock the screen, go outside.

---

## 🚀 Features

### 🐦 Zero-Signal Trail Acoustic Bio-Identifier
Analyzes ambient forest sound via edge-native Web Audio API FFT. Identifies 140+ native bird calls in under **42 milliseconds** on device. No internet required.

### 🍂 Fall Foliage Run Club & Route Builder
Synthesizes 3km–10km loop runs maximizing tree canopy density, autumn foliage index, and dirt-to-pavement ratio (88%+ singletrack). 4 turn cues designed to be memorized in 10 seconds.

### 🌱 Edge Frost-Date & Wild Sowing Almanac
Offline horticultural rules matrix based on USDA hardiness zones. Tells you the exact ground task for today — from garlic planting to mushroom gathering.

### ⏱️ 15-Second Screen-to-Dirt Protocol
Hard mathematical ratio: every second of screen time yields 120 seconds of outdoor immersion. 15-second countdown with forest wind synthesis, then the screen locks.

## ⚡ Quick Start

```bash
# Clone
git clone https://github.com/nonsense3/Touch-Grass.git
cd Touch-Grass

# Install
npm install

# Configure (copy and fill in your API key)
cp .env.example .env

# Run
npm run dev
```

Open `http://localhost:5173` — all tools work offline after initial load.

---

## 🔧 Environment Variables

```env
VITE_GEMMA_PROVIDER=nvidia-nim
VITE_NVIDIA_NIM_API_KEY=your_nvidia_nim_api_key
VITE_GEMMA_MODEL=gemma-4b
```

See [`.env.example`](./.env.example) for all available options.
